# HouseTeam

A magical Harry Potter-themed platform for finding hackathon teammates. Let the Sorting Hat guide you to your perfect team!

## Features

- **For Clubs**: Create hackathons, ideathons, datathons, and designathons
- **For Participants**: Browse events and find teammates with complementary skills
- **Sorting Hat AI**: Conversational interface to match teammates based on skills

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```
